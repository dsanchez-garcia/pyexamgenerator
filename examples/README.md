# Ficheros de ejemplo

PDF que usan los tutoriales de la documentación para generar preguntas con Gemini:

| Fichero | Contenido |
|---|---|
| `RD 31-95 LPRL_fragmento.pdf` | Fragmento de la Ley 31/1995 de Prevención de Riesgos Laborales (el que usa el tutorial). |
| `RD 39-97 RSP_fragmento.pdf` | Fragmento del Real Decreto 39/1997, Reglamento de los Servicios de Prevención (el que usa el tutorial). |
| `RD 31-95 LPRL.pdf` | Texto completo de la Ley 31/1995. |
| `RD 39-97 RSP.pdf` | Texto completo del Real Decreto 39/1997. |

Son textos legales públicos. Cópialos a tu carpeta de trabajo para seguir el
[tutorial de generación de preguntas](https://pyexamgenerator.readthedocs.io/es/latest/tutorial_pyexamgenerator_pt1_generar_preguntas.html).

Esta carpeta no forma parte del paquete que se instala con `pip`. No añadas aquí datos de alumnos.
